# Logo

小程序头像，2026-10-06 定稿。

- `logo.svg`：源文件，纯几何，改这个
- `logo-1024.png`：上传微信后台用（公众平台 → 设置 → 基本设置 → 小程序头像）

## 含义

一叠票根 = 很多场活动；前面那张印着几何化的东方明珠 = 在上海。
用两张票而不是一张，是为了避免被读成「东方明珠塔门票」。

## 颜色

和 `src/app/styles.css` 的 token 同值：底色 `--accent` `#c4472a`，前票 `--paper` `#fbfaf7`，后票与明珠 `--ink` `#191817`。

## 注意

- 不放进 `miniprogram/`：头像只在后台上传，打进包里会占体积。
- 名称、简介里不要出现「东方明珠」「官方」「售票」。
- 以后如果要注册商标，先在中国商标网检索第 35、41、42 类有没有东方明珠的图形商标。
