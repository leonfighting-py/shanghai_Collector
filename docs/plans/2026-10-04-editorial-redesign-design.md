# Web + 小程序前端改版：「素白」杂志编辑风

2026-10-04。起因：用户觉得两端「不够美观」。经过三轮高保真预览（`docs/preview/redesign-editorial.html`）确认了下面的方案。

## 定下来的决定

| 项 | 决定 | 备注 |
| --- | --- | --- |
| 视觉方向 | 杂志编辑风：纯色纸底 + 宋体标题 + 细线 + 一个强调色 | 丢掉液态玻璃、模糊、城市照片底 |
| 配色 | 「素白」，略带暖：浅 `#fbfaf7` / 深 `#201f1d`，强调色珊瑚橙 | 否掉了米黄（太常见）和纯黑 |
| 深浅色 | 跟随系统，不做手动切换 | 删掉 ThemeProvider / ThemeToggle |
| 站名 | 暂时保留「上海城市生活雷达」 | 「沪上双周」被否，之后可能再改 |
| Web 首屏 | 保留全屏插画 Hero，但只留标题、一句话、一个按钮 | 四角装饰文字、雷达动画、顶部导航条全部删掉 |
| 首页结构 | Hero → 本期数字 → 本期推荐（3 条）→ 正在进行（海报横滑）→ 吸顶筛选条 → 按天分组的日程表 | 类目只在筛选条出现一次 |
| 小程序首页 | 第一屏是插画封面 + 标题 + 三个数字，下面同样是海报栏 + 日程表 | 自定义导航，下滑后出现实色标题栏 |
| 跨天活动 | 占整个日期区间：首日、最后一天各出现一次，中间算「展期中」 | 见下 |

## 跨天活动怎么展示

旧版一档 10.14–10.30 的展览只挂在开始那天。新版每一天分三桶（`src/lib/agenda.js`）：

- **start**：当天开始。跨天的在时间下标「首日」，标题下写「10.10 — 10.17 · 共 8 天」。
- **last**：当天是最后一天，时间栏写「最后一天」。
- **run**：展期中。线上常年 60–80 场，不能每天平铺。

用户明确不接受「某天全是展期中就整天折叠成空白」。所以每天**至少露出 5 行**（小程序 3 行）：
当天 start + last 不够就从 run 里补，3 天内结束的优先，其余按天轮换起点；剩下的才折叠。

## 实现要点

- 日程表在客户端算：服务端一次给足 14 天窗口，类目 / 搜索 / 只看收藏都本地筛，切换零延迟。
  筛选状态用 `history.replaceState` 写回地址栏，`/?category=展览` 可直接分享。
- `/category/[name]` 改为重定向到 `/?category=`，旧链接不失效；sitemap 和 llms.txt 同步改了。
- Web 收藏沿用 localStorage（`useFavorites`），入口从独立的收藏栏改成筛选条上的「只看收藏」开关。
- 小程序的 `utils/agenda.js` 是 `src/lib/agenda.js` 的 CommonJS 移植，改规则时两边一起改。
- 只用系统字体。站点 CSP 是 `style-src 'self'`，Google Fonts 样式表本来就被拦（旧版的 Inter 其实一直没加载上）。

## 没做的

- 数据去重：同一场演出在格瓦拉和票牛各有一条，日程表里会相邻出现两次。属于采集侧的问题。
- 小程序 tabBar 图标、Web 活动详情页、日历月视图。
