# v2 升级说明

## 一、2.1 存在的问题

### 模型问题
1. **财务数据严重错误**：2024 年营收被报告为 57.32 亿港元（实际 37.72 亿 RMB），现金储备 433.4 亿港元（实际 127.52 亿 RMB）——数据来源为训练知识而非实际文档
2. **来源伪造**：声称的 HKEX 年报 PDF 实际是 404 错误页面（2057 字节 HTML），非真实年报
3. **币种混淆**：人民币和港元混用，导致增长率和规模严重失实

### Agent 问题
1. **Validator 门禁被绕过**：Skill 规定 Validator 失败不得继续，但实际 Agent 在 Validator 失败后仍继续生成报告
2. **长链路无状态**：模型上下文中断、API 限流或进程退出后，无法从检查点恢复
3. **证据边界违规**：判断如「PB 接近 1 = 下行空间有限」「现金可支撑 10 年」「H2 EBITDA 转正 = 盈利拐点」超出证据支持范围

### Skill 工程问题
1. **SKILL.md 过长**（585 行）：包含档位选择、失败路由、全部 Payload 和命令模板，对轻量模型造成上下文压力
2. **无确定性状态管理**：阶段顺序、重试次数、产物哈希均依赖 Agent 记忆
3. **无产物依赖失效机制**：上游 evidence 修改后，下游 content_units 和报告不会自动失效

## 二、v2 如何改进

| 问题 | v2 改进 | 类型 |
|---|---|---|
| 财务数据错误 | 从港交所披露易下载真实 PDF（4 份，HTTP 200），pypdf 提取全文验证 | 数据修正 |
| 来源伪造 | 修正 HKEX PDF URL（`MAR20250327013.pdf` → `2025032600615.pdf`） | 数据修正 |
| Validator 门禁被绕过 | 新增 `runner.py` 确定性状态机，Validator 失败强制阻断 | 工程改造 |
| 长链路无状态 | `run_state.json` + 原子写入 + `resume` 命令 | 工程改造 |
| 证据边界违规 | 现金跑道标注「情景估算，非确定事实」；增长率为程序复算 | 内容修正 |
| SKILL.md 过长 | 缩短至 173 行（-59%），Payload 移至 `references/stage-*.md` | 工程改造 |
| 产物依赖失效 | `artifact_hashes` + `check_stale_artifacts` + 下游自动标记 stale | 工程改造 |
| Demo 定位 | 从 Agent 控制台改为管理层决策页面（双决策入口 + 情景切换） | 产品升级 |

## 三、Demo 信息架构升级

### v1（研究展示）
- Agent 运行日志、研究回放
- Validator 调试信息
- 技术流水线展示
- Evidence JSON 直接暴露
- DEMO MODE 标记

### v2（管理层决策）
- 采购合作 + 投资观察双决策入口
- 首屏回答 5 个关键问题（是否合作、适合什么、是否投资、机会风险、下一步）
- Bull/Base/Bear 情景切换
- 风险触发器（当前状态 + 监测指标 + 时间窗口 + 影响 + 管理层动作）
- 附录只保留指标口径、来源、缺口、声明
