This guide will walk you through how to use SenseNova within LobeHub. Step 1: Obtain Your SenseNova API Key Register and log in to the SenseCore AI Studio In the product menu, locate and activate the SenseNova Large Model service Go to the AccessKey Management page Create a new access key Save the AccessKey ID and Secret Token from the pop-up window Make sure to save the access key shown in the pop-up window. It will only be displayed once. If you lose it, you’ll need to generate a new one. Step 2: Configure SenseNova in LobeHub Open the Settings panel in LobeHub Under AI Providers , find the configuration section for SenseTime SenseNova Enter your AccessKey ID and AccessKey Secret Choose a SenseNova model for your AI assistant to start chatting You may incur charges when using the API services. Please refer to SenseNova’s pricing policy for more details. And that’s it! You’re now ready to use SenseTime SenseNova models in LobeHub for intelligent conversations.
