# 商汤科技深度研究报告 — 网页化 Plan（美化修订 v2）

## 受众 / 用途

- **读者**：ToB 企业管理层（采购决策者 + 投资决策者）
- **任务**：辅助判断「是否合作」和「是否列入投资观察名单」
- **用途**：PC Web 端辅助展示，用于内部讨论、评审或对外分享
- **阅读模式**：通读 + 跳读并存

## 短设计计划

### 内容信号

- **领域**：AI 行业 / 企业采购评估 / 港股投资研究
- **场景与工具**：彭博终端、财报分析台、交易屏、决策备忘
- **内容任务**：解释（基本面）、比较（竞争梯队）、决策（采购/投资）、预警（风险缺口）
- **情绪温度**：冷静、精密、证据驱动、谨慎乐观（琥珀色）
- **关键叙事**：2025 盈利拐点比预期更早（H2 EBITDA 转正），全年仍亏损；视觉多模态为护城河

### 候选方向

#### A：交易终端 / 分析控制台（选定）
- **内容联系**：标的为港股 00020.HK；核心是财务轨迹、估值、决策条件。交易终端视觉语言——深底、等宽数字、轨迹线、分割线——属于该领域。
- **Color**：`#070b14` 背景 / `#e6e1d4` 暖白正文 / `#e8a317` 琥珀强调 / `#c43c4e` 风险红 / `#4a8fd4` 冷蓝中性 / `#6a7388` 注释
- **Type**：display = Noto Serif SC / body = Noto Sans SC / mono = JetBrains Mono
- **Layout**：左栏导航 + 右侧长读；首屏全幅股价轨迹，KPI 改为账本行而非卡片墙
- **Signature**：IPO→现价股价轨迹折线 + 采购/投资双栏对照 + 竞争梯队横向定位

#### B：学术白皮书
- 落选：决策者需要仪表盘即视感，印刷感削弱可操作性。

#### C：AI 产品官网风
- 落选：紫蓝渐变/发光与严肃金融分析冲突，SKILL 禁止该套路。

### 选定方向与相对独特性审查

选定 A。v1 实现落入「深色 + 圆角卡片墙 + 首屏四格 KPI」通用仪表盘套路。

**v2 修改点**：
1. 首屏去掉四格统计卡，改为顶部 ticker 条 + 全幅轨迹为主焦点
2. KPI / 现金 / 产品改为账本行与索引行，取消圆角卡片墙
3. 状态标签改为直角小标，去掉 pill 簇
4. 圆角从 10px 收到 2px，更接近终端面板而非 SaaS 卡片

换报告测试：股价轨迹、ticker、双结论对照换到教育报告不成立 → 通过。

## 首屏策略

- **代表物**：IPO→2026.07 股价轨迹（全幅）
- **领读**：「盈利拐点比预期更早，但全年仍亏损」
- **焦点**：轨迹线 + 现价 1.360 HKD 标注
- **图地**：折线在前，网格在后；ticker 条仅作上下文，不抢焦点

## 信息结构与版式策略

- **拓扑**：单文档滚动 + 左栏 scrollspy
- **骨架**：`--nav-width` 220px + 主栏；正文 `--measure` 640px，宽块 `--wide` 1120px
- **导航**：7–9 锚点；品牌区显示代码与现价
- **节奏**：首屏破格 → 摘要账本行 → 双栏结论 → 密集财务 → 轻量竞争梯队 → 产品索引 → 风险边注 → 结论时间线

## 设计契约

- **tokens**：见上表，全部入 `:root`
- **字体**：Noto Serif SC / Noto Sans SC / JetBrains Mono（Google Fonts link）
- **宽度档**：measure 640 / wide 1120 / page-pad 40 / nav 220
- **章版面映射**：见上表
- **图表清单**：①股价轨迹 ②营收柱 2021–2025 ③亏损收窄示意 ④竞争梯队（无发明精确股价中间点，轨迹为示意斜率，节点标注来自原文）
- **动效**：轨迹 draw、章节 reveal、scrollspy；reduced-motion 关闭
- **响应式**：≤768 导航导航；双栏改单列；表横向局部滚
- **事实边界**：数字仅来自 report.md；2025 数据标新闻稿；缺口标未解决；非投资建议
- **泛模板自检**：去掉卡片墙与 pill 后，独特性依赖股价轨迹与双结论对照
